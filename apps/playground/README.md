# dune playground

Vite + shadcn/ui (Base UI / `base-nova`) sandbox for [`@suveshmoza/dune-charts`](../../packages/dune-charts).

## Run

From the repo root:

```bash
pnpm dev
```

Or:

```bash
pnpm --filter playground dev
```

Add components with:

```bash
pnpm --filter playground exec shadcn@latest add <component>
```
